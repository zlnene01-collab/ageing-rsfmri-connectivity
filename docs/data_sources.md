# Data Sources

## Primary Dataset

This project will use OpenNeuro dataset **ds003592**:

**Dataset title:** Neurocognitive aging data release with behavioral, structural, and multi-echo functional MRI measures  
**OpenNeuro accession number:** ds003592  
**Dataset link:** https://openneuro.org/datasets/ds003592/versions/1.0.13

## Dataset Description

This dataset includes neurocognitive ageing data from younger and older adults. It contains structural MRI, multi-echo resting-state fMRI, and behavioral measures.

This project will focus mainly on resting-state fMRI data and age-related differences in selected brain networks.
